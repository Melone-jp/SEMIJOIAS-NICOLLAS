# Histórico da conversa e evolução do projeto

Este arquivo registra o contexto da criação e evolução do dashboard Semijoias MR.

## Visão geral
- Projeto criado em PHP para uso local com XAMPP.
- Dashboard com Bootstrap e JavaScript.
- Login com credenciais administrativas.
- Integração com banco MySQL e arquivo SQL do projeto.
- Estrutura de módulos: dashboard, pedidos, comissões, caixa e usuários.
- Interface profissional, sem emojis.
